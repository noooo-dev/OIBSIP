# Unit Converter — Java + XML

A simple Android Unit Converter built with Android Studio, Java, XML, Spinner, EditText, TextView, Button, and Toast.

## Features

- Numeric input
- Category selector
- Length conversion
- Weight conversion
- Volume conversion
- Temperature conversion
- Source and target unit Spinners
- Convert button
- Result with unit labels
- Empty/non-numeric input validation using Toast
- Changing category resets the unit selections

## Tech Stack

- Android Studio
- Java
- XML
- AndroidX AppCompat
- Material 3
- ConstraintLayout

## Run

1. Open this folder in Android Studio.
2. Let Gradle sync.
3. Install/use an Android emulator or physical device.
4. Click Run.
5. Select a category, enter a number, choose source/target units, and press Convert.

## Example

10 centimetres -> 0.3937 inches
