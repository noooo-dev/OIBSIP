# Setup

## Recommended environment

- Android Studio
- JDK 17
- Android SDK Platform 35
- Android SDK Build-Tools
- Android Emulator (optional if using a physical device)

## Open project

Open the folder containing `settings.gradle`.

## If Gradle asks for a JDK

Use the JDK bundled with Android Studio / Android Studio's Gradle JDK, provided it is JDK 17.

## Run

Create/start an emulator, select it in Android Studio, then press Run.
